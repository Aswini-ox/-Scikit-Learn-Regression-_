# Day 3 - Scikit-Learn Regression 🏠

## 📌 Project Overview
This project demonstrates a simple Linear Regression model using Python and Scikit-Learn to predict housing prices. The model is trained using the California Housing dataset and evaluated using Mean Squared Error (MSE) and R² Score.

## 🎯 Objectives
- Understand Linear Regression.
- Load and explore a housing dataset.
- Split data into training and testing sets.
- Train a regression model using Scikit-Learn.
- Predict housing prices.
- Evaluate model performance using MSE and R² Score.
- Visualize actual and predicted housing prices.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## 📂 Dataset
**California Housing Dataset**

The dataset contains housing information from California.

- Total records: 20,640
- Features: 8 input features
- Target: Median House Value

For this simple linear regression experiment:
- **Input Feature:** Median Income (`MedInc`)
- **Target Variable:** Median House Value (`MedHouseVal`)

## ⚙️ Implementation Steps
1. Imported the required Python libraries.
2. Loaded the California Housing dataset.
3. Selected input and target variables.
4. Split the dataset into 80% training and 20% testing data.
5. Created and trained a Linear Regression model.
6. Predicted housing prices.
7. Evaluated the model using MSE and R² Score.
8. Visualized actual and predicted prices.

## 📊 Model Evaluation
The model performance is measured using:

- **Mean Squared Error (MSE):** Measures the average squared prediction error. Lower values indicate smaller errors.
- **R² Score:** Measures how much variation in the target variable is explained by the model.
